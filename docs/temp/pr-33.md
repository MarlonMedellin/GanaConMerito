Ejecuta validación completa en el VPS para GanaConMerito.

IMPORTANTE:
- Para Playwright usa Chromium.
- NO uses Google Chrome.
- Chrome no funciona en este entorno.
- Chromium sí funciona con Playwright.

Variables:

SOURCE_DIR=~/.openclaw/product
DEPLOY_DIR=/opt/gcm/app
COMPOSE_FILE=/opt/gcm/docker-compose.yml
LOCAL_URL=http://127.0.0.1:3000
PUBLIC_URL=https://cnsc.profemarlon.com

1. Actualizar fuente:

cd ~/.openclaw/product
git fetch origin --prune
git checkout master
git pull --ff-only origin master
git rev-parse HEAD
git rev-parse --short HEAD

2. Actualizar deploy:

cd /opt/gcm/app
git fetch origin --prune
git checkout master
git reset --hard origin/master
git rev-parse HEAD
git rev-parse --short HEAD

3. Instalar dependencias:

cd /opt/gcm/app
npm install

4. Ejecutar tests internos del VPS, sin navegador live:

npm run lint
npm run build
npm run test:recent-sprints
npm run test:unit

Estos deben validar:
- Sprint 33 cerrado operacionalmente
- Sprint 34 como sprint vigente
- tolerancia semántica avg_difficulty = 0.02
- estado normativo synthesized_governed_unverified
- dashboard
- tutor
- recent-sprints

5. Reconstruir Docker:

cd /opt/gcm/app
export APP_COMMIT=$(git rev-parse HEAD)
export APP_BUILD_TIME=$(date -u +%Y-%m-%dT%H:%M:%SZ)

docker compose -f /opt/gcm/docker-compose.yml build \
  --build-arg APP_COMMIT="$APP_COMMIT" \
  --build-arg APP_BUILD_TIME="$APP_BUILD_TIME" \
  gcm-app

6. Reiniciar app:

docker compose -f /opt/gcm/docker-compose.yml up -d gcm-app
docker compose -f /opt/gcm/docker-compose.yml ps

7. Smoke interno local del VPS:

cd /opt/gcm/app

QA_BASE_URL=http://127.0.0.1:3000 \
REQUIRE_RUNTIME_METADATA=1 \
npm run qa:runtime:smoke

QA_BASE_URL=http://127.0.0.1:3000 \
npm run qa:smoke:postdeploy

8. Smoke público live:

QA_BASE_URL=https://cnsc.profemarlon.com \
REQUIRE_RUNTIME_METADATA=1 \
npm run qa:runtime:smoke

QA_BASE_URL=https://cnsc.profemarlon.com \
npm run qa:smoke:postdeploy

9. Preparar Chromium para Playwright:

cd /opt/gcm/app

npx playwright install chromium
npx playwright install-deps chromium

NO ejecutar:
npx playwright install chrome

NO usar canal Chrome.
Usar únicamente Chromium.

10. Ejecutar Playwright live con Chromium:

QA_BASE_URL=https://cnsc.profemarlon.com \
npm run qa:e2e:api

QA_BASE_URL=https://cnsc.profemarlon.com \
npm run qa:e2e:ui

11. Verificación final:

curl -s https://cnsc.profemarlon.com/login | grep -i "commit"
curl -s https://cnsc.profemarlon.com/login | grep -i "build"
docker logs --tail=200 gcm-app

Criterio de éxito:
- source y deploy en el mismo commit
- Docker build PASS
- gcm-app running
- lint PASS
- build PASS
- test:recent-sprints PASS
- test:unit PASS
- smoke local PASS
- smoke público PASS
- qa:e2e:api PASS
- qa:e2e:ui PASS usando Chromium
- commit visible en /login coincide con HEAD
- buildTime visible y actualizado

Reporte final requerido:
1. commit largo y corto
2. resultado de actualización source
3. resultado de actualización deploy
4. resultado Docker build/restart
5. resultado tests internos
6. resultado smoke local
7. resultado smoke público
8. resultado Playwright API con Chromium
9. resultado Playwright UI con Chromium
10. commit/buildTime observado en URL pública
11. errores con stdout/stderr si existen
12. conclusión final:
   - Deployment Status
   - Operational Status
   - Sprint actual
   - si Sprint 33 queda cerrado
