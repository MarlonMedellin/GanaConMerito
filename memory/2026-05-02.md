# 2026-05-02 - Diagnóstico de Login Roto

## Resumen
El usuario reportó que el login está roto y se queda en "Conectando...". Se realizó una auditoría E2E y se identificó que faltan las variables de entorno de Supabase en el cliente.

## Acciones realizadas
1. Se leyó la configuración de AGENTS.md y se inicializó la sesión.
2. Se corrigió un error de sintaxis en `package.json` que impedía ejecutar scripts.
3. Se creó un script de auditoría E2E específico para el login (`scripts/audit-login.ts`).
4. Se ejecutó la auditoría localmente contra la URL de producción (`https://cnsc.profemarlon.com/login`).
5. Se intentó conectar al VPS OCI vía SSH, pero la conexión resultó extremadamente lenta/inestable.

## Hallazgos
- El botón de login se queda bloqueado en "Conectando..." debido a una excepción no capturada en `GoogleSignInButton.tsx`.
- La excepción es: `Missing Supabase browser environment variables.`.
- Esto indica que `NEXT_PUBLIC_SUPABASE_URL` y `NEXT_PUBLIC_SUPABASE_ANON_KEY` no están definidas en el entorno de ejecución/build de producción.
