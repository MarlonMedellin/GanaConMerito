# Guías

Destino de guías oficiales o metodológicas reutilizables para generación, auditoría y explicación de reactivos.

Una guía debe registrarse con entidad/autores, edición o fecha, URL/procedencia, localizador y estado de verificación. Si una guía cambia con frecuencia, conservar la versión o fecha que soporta el reactivo.

La pertenencia a una familia, perfil/cargo u OPEC se modela mediante mapas, no copiando la guía en varias carpetas.
