# Fuentes técnicas

Destino de documentos técnicos, manuales, especificaciones y referencias operativas que sustentan conocimiento evaluable.

Cada entrada debe distinguir entre documento fuente, resumen editorial y notas internas. No almacenar como “fuente” una interpretación sin procedencia verificable.

Cuando el documento sea versionado, registrar versión/fecha y evitar que una revisión posterior sobrescriba silenciosamente la referencia usada por reactivos existentes.
