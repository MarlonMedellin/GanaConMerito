# Fuentes académicas

Destino de referencias académicas normalizadas: teorías, investigaciones, marcos pedagógicos y literatura científica.

Guardar documentos completos solo cuando exista derecho o licencia. En los demás casos conservar metadatos, cita, URL/DOI y notas o extractos permitidos.

Antes de usar una fuente para construir un reactivo debe poder identificarse el autor, la obra, la edición/publicación pertinente y el localizador que respalda la afirmación evaluada.
