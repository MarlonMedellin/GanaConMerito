# Fuentes normativas

Destino de normas y referencias normativas **normalizadas y verificadas**.

No copiar aquí automáticamente archivos de `content/normative/`. Esa ruta contiene material legacy que primero debe inventariarse, contrastarse con fuente oficial y completar metadatos.

Una entrada normativa debería registrar, cuando aplique: autoridad emisora, tipo/número/año, título, vigencia, URL oficial, fecha de verificación, modificaciones/derogaciones relevantes y localizadores usados por reactivos.

La aplicabilidad a familia, perfil/cargo u OPEC pertenece a `../../maps/`, no a duplicaciones de la norma.
