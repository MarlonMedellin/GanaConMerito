# Temarios y mapas base — docentes

Esta carpeta aloja documentos de temas, blueprints y mapas de cobertura que sirven como **insumos de planeación** para la familia `docentes`.

## Temario base

El documento de trabajo derivado del Markdown aportado por el usuario se conserva en:

```text
content/knowledge-base/themes/docentes/temario-base.md
```

La verificación de integridad realizada sobre la copia actual demostró que **todavía no es byte a byte idéntica al archivo original `temas(3).md`**. La evidencia, hashes y condición de cierre están documentados en:

```text
content/knowledge-base/themes/docentes/INTEGRITY.md
```

Hasta restaurar o documentar completamente esa diferencia, no describir `temario-base.md` como copia exacta del original.

Debe tratarse como **fuente de planeación**, no como taxonomía canónica ni como banco de reactivos. Su contenido puede contener formulaciones históricas, hipótesis, preguntas de trabajo, duplicados o referencias que requieren verificación normativa; por tanto, ninguna entrada se promueve automáticamente a `topic`, reactivo ni fuente normativa verificada.

## Regla de uso

Un encabezado o entrada del temario:

- puede señalar una oportunidad de cobertura;
- no se convierte automáticamente en `topic`;
- no obliga a crear una pregunta;
- debe contrastarse contra el banco activo para evitar duplicación;
- debe apoyarse en fuentes verificables antes de producir un reactivo;
- debe clasificarse por familia/perfil/OPEC mediante targeting, sin duplicar el temario.

## Relación con perfiles docentes

El temario contiene contenidos comunes y otros potencialmente relevantes para perfiles específicos. Esa aplicabilidad se documenta mediante los mapas/catálogos de `content/targeting/` y `content/knowledge-base/maps/`, no duplicando el temario.

Perfiles iniciales:

- `coordinador`
- `docente_aula_preescolar`
- `docente_aula_basica_primaria`
- `docente_aula_secundaria_media`
- `docente_orientador`

## Gobernanza

Antes de derivar una pregunta desde este temario, el agente debe comprobar:

1. si el constructo ya existe en V4;
2. qué fuente normativa, técnica o académica lo sustenta;
3. si la fuente está vigente y correctamente localizada;
4. a qué familia, perfil/cargo y, cuando corresponda, OPEC aplica;
5. si la necesidad se resuelve mediante taxonomía, targeting o una nueva pregunta.
