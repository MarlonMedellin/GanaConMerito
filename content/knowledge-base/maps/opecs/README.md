# Mapas de conocimiento por OPEC

Aquí se relacionarán fuentes verificadas con OPEC **reales** registradas en `content/targeting/opecs/`.

Una OPEC puede añadir manuales de funciones, documentos de convocatoria, normativa de entidad o contenidos técnicos exclusivos. Esas relaciones se suman a la base heredada de familia y perfil.

No crear OPEC ficticias ni usar el nombre de un cargo como sustituto de una identidad OPEC concreta.
