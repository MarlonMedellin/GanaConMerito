# Mapas de conocimiento por perfil/cargo

Aquí se relacionarán fuentes verificadas con los `profileCode` canónicos de `content/targeting/profiles/`.

Una relación de perfil representa relevancia diferencial para ese cargo; no crea una copia de la fuente ni implica que todas las preguntas del perfil deban usarla.

No generar mapas mediante coincidencia de palabras clave. La relación debe apoyarse en funciones, ámbito normativo/técnico o necesidad evaluativa comprobada.
