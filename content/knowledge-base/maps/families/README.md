# Mapas de conocimiento por familia

Aquí se relacionarán fuentes **verificadas** con familias canónicas de `content/targeting/families/`.

No crear un mapa por intuición temática. Cada relación debe citar `sourceId`, justificar por qué la fuente es común a la familia y registrar estado/verificación.

Para docentes, el archivo futuro será `docentes.json` únicamente cuando existan fuentes verificadas suficientes para sostener la base común.
