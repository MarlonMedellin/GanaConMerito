# Estados de consolidacion

## PRECONSOLIDADO
Item ya auditado pero aun no integrado al indice maestro.

## CONSOLIDADO
Item validado para integracion transversal.

## CUARENTENA_OPERATIVA
Item o lote separado por riesgo documental.

## NO_RECUPERABLE
Fuente rota o inconsistente.

## PENDIENTE_NORMALIZACION
Item con problemas de nomenclatura, ids o rutas.

## EXCLUIDO_OPERACIONALMENTE
Conserva trazabilidad historica pero no puede entrar al banco limpio.
