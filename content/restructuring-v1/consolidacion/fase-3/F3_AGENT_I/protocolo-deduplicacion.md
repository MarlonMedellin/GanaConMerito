# Protocolo de deduplicacion

## Objetivo
Detectar items repetidos o semanticamente equivalentes.

## Niveles
### Nivel 1
Mismo ID exacto.

### Nivel 2
Misma situacion con pequenas variaciones.

### Nivel 3
Misma competencia medida con distractores diferentes.

## Regla
Conservar:
- mayor calidad psicometrica,
- mejor trazabilidad,
- fuente recuperable,
- mejor defendibilidad.

## Prohibido
- fusionar automaticamente,
- sobrescribir lotes historicos,
- borrar evidencia previa.
