# banco-operacional-previo

Preguntas que estaban en `content/items` antes del saneamiento beta y que no son la carpeta operativa final.

Incluye JSON y Markdown previos, carpetas por area canonica y algunas carpetas tematicas historicas. Se conservan para trazabilidad, comparacion y posible recuperacion posterior.

## Uso

- Consultar como fuente historica.
- No usar como runtime beta.
- Promover a beta solo mediante el indice maestro y regeneracion de `content/items/beta-v1`.
