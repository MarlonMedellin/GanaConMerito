# content/profiles

Esta carpeta agrupa vistas secundarias del banco por perfiles profesionales.

## Propósito

Sirve para:
- planeación editorial
- curación de lotes
- mapeo entre perfiles y taxonomía
- organización operativa por cargo

## Regla

Los ítems definitivos no deben duplicarse aquí si ya existen en `content/items/`.

La carpeta de perfiles no es banco de preguntas. Es una capa de lectura para decidir afinidad, balance y cobertura por cargo.

## Uso beta

Las vistas oficiales de pilotaje por perfil se generan desde:

```text
content/restructuring-v1/00-beta-v1/piloto-v1/por-perfil/
```

Estas vistas sirven para balance y revision humana. No reemplazan el banco canonico ni deben duplicar archivos de preguntas.
